# คู่มือทีมแปล COH1T (v1)

## โครงสร้างไฟล์

```
work/translate_parts_v2/
├── 01_ui/           UI: ระบบ/เมนูหลัก/ล็อบบี้/Workshop (6 ไฟล์)
├── 02_units/        หน่วยรบ: ชื่อ/คำอธิบาย/สถิติอาวุธ (3 ไฟล์)
├── 03_normandy/     แคมเปญนอร์มังดี แยกตามภารกิจ M01–M16 + เทรนนิ่ง (16 ไฟล์)
├── 04_expansions/   แคมเปญเสริม: ก็อง/มาร์เก็ตการ์เดน/ไทเกอร์เอซ/ปฏิบัติการ (5 ไฟล์)
└── 05_speech/       เสียงพากย์: ตัวเลขเสียง (1 ไฟล์)
```

แต่ละไฟล์ = CSV คอลัมน์:

| คอลัมน์ | ความหมาย | แก้ได้ไหม |
|---|---|---|
| `id` | ID ตัวแทนของแถว | ❌ ห้าม |
| `english` | ต้นฉบับ | ❌ ห้าม |
| `thai` | คำแปล (แก้ตรงนี้ที่เดียว) | ✅ |
| `context` | บริบทในเกม (หัวข้อ/ภารกิจ/ปุ่ม) | ✅ เติมได้ถ้าช่วยจำ |
| `all_ids` | ทุก ID ที่ใช้ข้อความนี้ (คั่นด้วย `\|`) | ⚠️ แก้ได้เฉพาะตอน "แยกแถว" (ดูหัวข้อ 4) |

## กติกา 7 ข้อ

1. **แก้เฉพาะคอลัมน์ `thai`** (และ `context` เติมได้) — `id`/`english`/`all_ids` คือกุญแจของระบบ ถ้าเพี้ยนจะแปลผิด ID ทันที
2. **placeholder ต้องคงครบและตรงชื่อ** — เกมจะแทนค่าพารามิเตอร์ด้วยชื่อเป๊ะ:

   | ตัวอย่าง | ใช้แทนอะไร |
   |---|---|
   | `%1HOTKEY%` | ปุ่มลัดจากตั้งค่าเกม |
   | `%1CAMPAIGN_NAME%` | ชื่อแคมเปญ |
   | `%1%`, `%2%`, `%s`, `%d` | พารามิเตอร์ลำดับ |
   | `$COLOR`, `[b]...[/b]`, `[c:red]` | สี/ตัวหนา |

   ❌ `(%1HOTKEY%)` → `(%1%)` คือพัง (เกมหา HOTKEY ไม่เจอ) — validator จะจับให้แต่แก้ด้วยนะ
3. **ชื่อเฉพาะ/รหัสภายในอย่าแปล** — `GillSans_18a`, `century14`, `RelicCOH`, `Steam` (เว้น glossary กำหนด)
4. **ศัพท์ยึด `glossary.md`** — คำเดียวกันทั้งเกมต้องเหมือนกัน (Skirmish = ศึกประจัญบาน เสมอ)
5. **ความยาวพอดี** — UI มีกรอบจำกัด ถ้ายาวกว่าเดิมมากจะล้น; ชื่อยูนิต/ปุ่มควร ≤ 25 ตัวอักษร
6. **น้ำเสียงตามหมวด** — 03/04 บทพูดภารกิจ = แนวภาพยนตร์สงคราม (อารมณ์, สแลงทหาร); 02 = กระชับ ศัพท์ทหาร; 01 = ตรงไปตรงมา
7. **แยกแถวเมื่อบริบทต่าง** (หัวข้อ 4) — อย่าเปลี่ยน `id` อย่างเดียว

## การแยกแถว (ข้อความเดียวกันแปลต่างกันตามบริบท)

เช่น "CONTINUE" — ปุ่มกับ tooltip อยากให้ต่าง:

```
ก่อน:  id=713500  CONTINUE  เล่นต่อ  context  all_ids=713500|713524|713526
หลัง:  id=713500  CONTINUE  เล่นต่อ      all_ids=713500|713524   (ปุ่ม)
       id=713526  CONTINUE  เล่นต่อจากเดิม  all_ids=713526        (tooltip)
```

กติกา: **ทุก ID ต้องมีอยู่ในแถวเดียวเสมอ** — แยกแล้วต้องไม่ซ้อน ไม่หล่น (validator เตือนถ้าซ้ำ)

## Workflow รอบส่งงาน

1. แปล/เกลาไฟล์ → ส่งโฟลเดอร์ `translate_parts_v2` กลับมา
2. ฝั่ง mod รัน `validate_translations` (จับ placeholder พัง + ละตินปน + coverage) → ส่งรายการให้แก้ถ้ามี
3. `apply` → เข้าเกมเทสต์ → แจ้งผล (คำไหนล้นกรอบ/อ่านแปลก จะส่งกลับจุดนั้น)
