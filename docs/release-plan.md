- [ ] ความยาวข้อความไทยไม่ล้นกรอบปุ่ม/กล่อง (จดรายการที่ล้น → ส่งทีมแปลย่อ)
- [ ] ความละเอียด 1280x960 + 1920x1080 + โหมด windowed
- [ ] รันผ่าน Steam และรัน exe ตรง — ทั้งสองทาง
- [ ] เล่นจริง 1 แมตช์: ข้อความในแมตช์ส่วนที่ยังเป็นอังกฤษแสดงปกติ ไม่มีกล่อง/squares

- [ ] ย้อนกลับได้: uninstall แล้วเกมกลับอังกฤษปกติ 100%

## แพ็กเกจ (ตัดสินใจ: แจก patch เล็ก ไม่แจก Engine.sga ทั้งก้อน)

Engine.sga เต็ม = 367MB แต่ที่เปลี่ยนจริง = 3 สล็อตฟอนต์ (~96KB × 3 + CRC) — แจกแบบ patch:

- [ ] เขียน `tools/apply_patch.py`: อ่าน Engine.sga ต้นฉบับ (hash ต้องตรง vanilla) → เขียน 3 slot + CRC → เช็คผล
- [ ] ไฟล์ patch = dict {offset: bytes} เฉพาะบล็อกที่ต่าง (ขนาด ~300KB) — แจกพร้อม .ucs
- [ ] สำรองไฟล์ patch ของ vanilla hash ผิดเวอร์ชัน (กัน Steam อัปเดตเกมแล้วใช้ไม่ได้ → ต้อง rebuild)

## ตัวติดตั้ง

- [ ] `install.bat` (PowerShell): หาโฟลเดอร์เกมอัตโนมัติ (Steam registry + ไล่ path มาตรฐาน) → backup .ucs + Engine.sga → ลง patch + .ucs → รายงานผลสำเร็จ/ล้มเหลว
- [ ] `uninstall.bat`: คืนไฟล์ backup ทุกตัว → ตรวจ hash กลับเป็น vanilla
- [ ] กันไฟล์ถูกแก้ขณะเกมเปิด (เช็ค process RelicCOH ก่อนทำทุกอย่าง)

## Pipeline ตอนรับไฟล์แปล (ทีละเวอร์ชัน)

```
merge_parts → pua_font_builder (cluster ใหม่) → apply → patch_sga
  → deploy ลงเครื่องเทสต์ → QA checklist ด้านบน → แพ็ก + release
```

## หมายเหตุสิทธิ์/ความเสี่ยง

- Steam อัปเดตเกมอาจทับไฟล์ → ผู้เล่นลงใหม่ หรือเราออก patch เวอร์ชันใหม่
- Workshop ลงไม่ได้ (รองรับแค่แผนที่) — แจกแบบธรรมดาเท่านั้น
- ฟอนต์ Leelawadee ฝังใน Engine.sga เป็นการแก้ไขเฉพาะเครื่องผู้ใช้ ไม่ขาย/ไม่โหลดฟอนต์ให้
